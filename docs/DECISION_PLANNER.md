# 이사 의사결정 플래너

구현일: 2026-09-10. 요구사항 77의 구현 기록.

## 가장 짧은 사용 순서

1. 대출 관리에서 보유 현금, 비상자금, 감당할 월 주거비를 확인한다.
2. 추천에서 단지와 전용면적을 고르고 `이 집 계산`을 누른다.
3. 홈에서 부족자금과 37개월차 부담을 확인한다.
4. 이사 후보지에서 현재 집 유지와 비교한다. 순자산 비교에 필요한 실수령·생활비·기존 대출 조건은 한 번 입력한다.

숫자가 없으면 확인 필요로 남긴다. 교통수단·배우자 소득·현금·분담금을 임의의 확정 사실로 채우지 않는다.

## 구현한 기능

- 단순한 홈: 선택한 집, 추가 필요자금, 거치 중/37개월차 주거비, 남는 월 저축, 비교 후보.
- 후보별 매수가·면적·KB 상하한·세금·수리비·관리비·교통비·보유세 조건. 매수가는 최근 실거래를 기본으로 쓰고 직접 수정 가능.
- 우리집 59㎡ 최근 거래가를 최초 매도가로 적용. 사용자가 저장한 값은 다음 동기화로 덮어쓰지 않음.
- 사내 5억원/매수가 70%/KB 평균 70% 최솟값, 36개월 거치와 120개월 상환, 개인 이자와 회사 지원분 추가세금 분리.
- 신용대출 이자만 납부 기본값. 만기 원금은 월별 실제 납부와 순자산 시나리오에 포함. 156개월 CSV 제공.
- 37개월차 원금·사내 개인 이자·신용 이자·지원분 추가세금·보유세·유지비를 결과 옆에서 바로 펼쳐보기.
- 세금·매도/매수 복비·이사·수리·비상자금을 포함한 자금 부족, 매수 상한, 매도가/금리 악화 시나리오.
- 계약금·매도 잔금·매수 잔금 날짜별 부족자금. 같은 날 지급 순서와 브리지 대출은 자동 추정하지 않음.
- 후보 저장, 최대 3곳 비교, 모바일은 현재 집과 선택한 한 곳을 나란히 표시. 직접 후보와 방문 메모 추가.
- 3년/5년 현재 집 유지 대비 보유 순자산과 손익분기 주택가치. 가격·현금 수익률은 사용자 가정이며 예측 점수 제거.
- 출퇴근은 확인한 편도 시간으로 비교. 실제 목적지·근무일·통근 상한과 후보별 확인일 저장, 네이버 지도 연결.
- 추천의 지역·가격·최소 면적·거래 신선도·자금/통근 필터와 부담/최근 거래/가격/거래량 정렬.
- 현재가가 아니라 거래일·층·12개월 거래량·최근 거래 3건을 함께 표시. 데이터 수집일과 거래일 구분.
- 관심 후보 위치는 검증된 좌표만 표시. 좌표가 없는 집은 네이버 지도 검색 링크 제공.
- localStorage 저장, JSON 내보내기/가져오기와 형식 검증. 서버 계정이나 자동 기기간 공유 기능은 없음.

## 계산 가정과 한계

매도 순자금 = 매도가 − 남은 주담대 − 매도 복비 − 직접 입력한 양도세/중도상환 등 비용.

매수 후 현금 = 매도 순자금 + 보유 현금 + 사내/신용대출 − 매수가 − 취득세 등 − 매수 복비 − 이사/수리/기타 비용.

부족자금 = 비상자금 목표 − 매수 후 현금의 양수 부분. 정기 월 부담과 만기 원금은 구분한다.

회사 원리금균등은 총금리 4.6%로 원금 일정을 만든 뒤 개인 1.5% 이자와 지원분 세금을 합산하는 계약 가정이다. 원금균등도 선택 가능하다. 실제 회사의 상환 방식·지원 종료·퇴사 조건은 별도로 확인해야 한다.

지원이자 세금은 세전 연봉에서 근로소득공제를 반영한 누진세 차액과 지방소득세를 월 단위로 단순 추정한다. 인적/연금 공제, 다른 소득, 보험료, 실제 연말정산은 미반영이다. 정확한 한계 부담률을 알고 있으면 직접 보정한다.

취득세는 일반 주택 유상 취득 기본세율 및 교육세, 전용 85㎡ 초과 농어촌특별세를 간이 반영한다. 주택 수·명의·지역·감면에 따른 중과/특례를 자동 판단하지 않으며 확정 세액 입력으로 대체할 수 있다. 복비는 상한이고 실제로 협의할 수 있다.

초기 예산 가정은 비상금 3,000만원, 수리 1,000만원, 이사 300만원, 등기·대출 부대비 200만원, 월 관리비 30만원이다. 양도세·교통비·보유세는 기본 0이므로 실제 조건에 맞게 보완해야 한다.

순자산 = 시나리오 주택가치 + 누적 현금 − 남은 대출. 양쪽에 같은 시작 현금과 소득을 적용하고 원금은 비용으로 이중 차감하지 않는다. 미래 매도세금 미포함인 보유 기준이다. 기간 중 현금이 음수면 추가 대출을 가정하지 않고 비교를 보류한다.

KB 미입력 또는 확인 후 30일 경과는 확정 적합 판정이 아니다. 기존 매교역푸르지오SKVIEW 84㎡ 참고값은 해당 후보에만 적용되며 오래된 확인일을 경고한다. 재건축 분담금·임시거주비도 확인 전에는 확정 적합으로 표시하지 않는다.

## 데이터와 개인정보

매일 KST 14시 기존 Action에서 실거래와 후보를 갱신한다. 기존 추적 구의 36개월 거래를 재사용하여 59~100㎡, 최근 12개월 내 최신 거래가 8.5~12억원 조건의 단지를 구별 최대 12곳 추가한다. 전체 수도권 시장이나 현재 매물의 전수 목록은 아니다. 주소·단지명으로 묶고 실패한 구는 이전 정상 데이터를 유지한다.

현재 매물·KB 계약 API·네이버 서버 Geocoding은 별도 설정이 필요하다. 미연결을 0건이나 정상 완료로 표현하지 않는다. 자동 길찾기, 확정 상승률 예측, 계정 기반 가족 공유는 구현하지 않았다.

입력한 가계 현금·소득·상세 근무지·메모는 해당 브라우저 저장소와 사용자가 내보낸 JSON에만 남으며 GitHub 데이터에 업로드하지 않는다. JSON은 개인 정보가 포함된 백업으로 다룬다. 지도 링크를 열면 검색한 위치는 지도 서비스에 전달된다.

## 검증

`node --test tests/*.test.cjs`: 금융 계산, 원금 보존, 만기, 순자산, 잔금, 후보 자동 발견/주소 분리/실패 복원 회귀 테스트.

`node tests/browser-smoke.cjs`: Playwright와 Chrome을 사용해 데스크톱·모바일 전체 탭, 입력 저장, 비교 시나리오, 후보 선택, JSON 백업/복원과 잘못된 파일 거절, 가로 넘침, JS 오류를 검사한다. 외부 API 인증과 출퇴근 정확도를 대신 검증하지 않는다.
